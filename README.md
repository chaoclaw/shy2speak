# Shy2Speak UI prototype

Responsive, dependency-free product prototype for the Shy2Speak language-learning platform.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

The prototype includes responsive desktop/mobile layouts, PWA installation metadata, theme and language controls, practice scoring, vocabulary, immersive listening, offline content management, an audio-to-HTML-PPT studio, AI settings, and account/privacy settings. All data and service actions are mocked for product review.
